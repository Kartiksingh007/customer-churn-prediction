# Customer Churn Prediction

End-to-end machine learning project for predicting whether a customer is likely to churn.

## Tech Stack
- Python
- Pandas / NumPy
- Scikit-learn
- XGBoost
- Random Forest
- Flask
- Joblib
- HTML/CSS/JavaScript

## Project Flow

Transaction Data
      ↓
Data Cleaning
      ↓
RFM Feature Engineering
      ↓
Train/Test Split
      ↓
Random Forest + XGBoost
      ↓
Model Evaluation
      ↓
Best Model Selection
      ↓
Save Model + Scaler
      ↓
Flask REST API
      ↓
Web Prediction UI

## RFM Features

For every customer:
- Recency: days since the customer's latest purchase
- Frequency: number of orders
- Monetary: total amount spent

Additional features:
- avg_order_value
- avg_quantity
- customer_lifetime_days

## Churn Definition

For this demo, a customer is considered churned when they have not purchased for more than the configured churn threshold.

The included `data/transactions.csv` is synthetic demo data generated by `generate_data.py`.
For a real company project, replace it with actual transaction/customer data.

## Run Locally

### 1. Create environment

Mac/Linux:

```bash
python3 -m venv venv
source venv/bin/activate
```

Windows:

```bash
python -m venv venv
venv\Scripts\activate
```

### 2. Install dependencies

```bash
pip install -r requirements.txt
```

### 3. Generate demo data

```bash
python generate_data.py
```

### 4. Train models

```bash
python train.py
```

This creates:
- `models/churn_model.joblib`
- `models/scaler.joblib`
- `models/feature_columns.joblib`
- `models/model_info.json`

It also prints accuracy, precision, recall, F1 and ROC-AUC for Random Forest and XGBoost.

### 5. Start Flask

```bash
python app.py
```

Open:

http://127.0.0.1:5000

## API

POST:

`/predict`

Example JSON:

```json
{
  "recency": 18,
  "frequency": 8,
  "monetary": 4200,
  "avg_order_value": 525,
  "avg_quantity": 3.2,
  "customer_lifetime_days": 180
}
```

Response:

```json
{
  "churn": 0,
  "prediction": "Not Churned",
  "churn_probability": 0.12
}
```

## Interview Explanation

"I built an end-to-end customer churn prediction system using RFM feature engineering. I transformed transaction-level data into customer-level Recency, Frequency and Monetary features, trained Random Forest and XGBoost classifiers, compared them using precision, recall, F1 and ROC-AUC, and selected the better model. I then serialized the preprocessing and model artifacts with Joblib and exposed the model through a Flask REST API for real-time predictions. I also added a lightweight web interface for testing predictions."
